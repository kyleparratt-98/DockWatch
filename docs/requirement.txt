Build a Python CLI tool that monitors local Docker container resource contention by scraping /sys/fs/cgroup and /proc filesystem metrics, extracts per-container CPU throttling, memory OOM scores, and I/O wait percentages, and visually outputs them to standard out using a real-time, color-coded ASCII heatmap grid with sparkline trends via the `rich` library's Layout and Panel widgets. It must handle edge-case scenarios where containers are ephemeral (PID recycling) or cgroup v2 paths differ from v1, falling back to `docker stats` API calls with graceful degradation and a warning banner.
